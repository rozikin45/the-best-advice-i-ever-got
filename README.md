A tiny program that writes one sentence of the best advice ever received — grandmother's warning about a quiet room full of nodding people — to `/output/entry.txt`.

## Run it

```sh
node main.ts
```

It writes exactly one sentence (108 characters, no trailing newline) to `/output/entry.txt`, deterministically — the same bytes on every run.
